## Paste-ready custom topic

Create a welcoming, practical Video Overview for Kreyco coaches and teachers explaining how to use the Classroom Creation Request portal. Assume the audience is comfortable completing online forms but does not need technical information about Google Apps Script, monday.com APIs, board IDs, or system administration.

Use the uploaded visual walkthrough screenshots as the primary on-screen examples. Follow screenshots 1-8 in order and zoom into the relevant button, field, progress indicator, or privacy message as it is explained.

Begin with the purpose of the request: it gives Kreyco Tech the class-specific information needed to create or update a classroom. Explain the two expectations shown on the welcome page: Tech can upload **3-5 lessons per class section per request**, and requests may take **2-5 business days** to complete.

Explain the most important organizing rule in simple language: **each class has its own request**. The request follows the class even if the assigned teacher changes. Adding another class creates another separate request; it does not add the class inside the first request.

Walk through the coach experience:

1. Accept the lesson limit and processing timeline.
2. Search for and select an active school.
3. Select the class.
4. Review the current teacher. Explain that the form can still be completed if no teacher has been assigned yet.
5. Use the assigned coach information when it appears, choose between assigned coaches when needed, or enter a manual coach contact.
6. Complete Language, Grade Level, Kreyco Curriculum, LMS verification, Google Classroom grading choice, other grading platform when needed, secure credential instructions, and schedule notes.
7. Review the information.
8. Choose Save as draft, Submit to Tech, or Submit & add another class.

Show that **Save as draft** does not notify Tech. The coach can return using the Classroom Request Form link on the class row or the private link provided to the coach. The class-row link is the reliable place to return to the request.

Show that **Submit to Tech** validates the required information, sends the request to Tech, and turns the class link into a progress summary. Explain the visible status, progress bar, latest public update, target completion date when available, and Refresh status button.

Explain the two ways a coach can follow up after submission:

- **Edit request details** changes the original form fields on the same request and notifies Tech.
- **Send additional information** adds a message without changing the form fields and notifies Tech.

Explain that the request is never duplicated during these updates. Tech continues working on the same class request.

Explain the teacher experience separately. The current teacher may receive a notification when Tech selects Coach + Teacher. The teacher's link is read-only and displays current progress. Teachers do not need the coach's private editing link. If the teacher assignment changes, the request remains with the class and the current-teacher information is updated by the system.

Include a privacy reminder:

- Prefer a password-manager secure-share link or access instructions instead of entering a reusable password.
- Treat the coach portal link as private because it permits editing and sending updates.
- A teacher progress link is read-only.
- Internal Tech Notes and credential contents are not displayed on the progress summary.

End with a short help checklist: use the current Classroom Request Form link from the class row, wait for the visible school/class loading message, refresh the summary if progress looks out of date, confirm the correct class before submitting, and contact Kreyco Tech Support if the class is missing, the link is invalid, or the request is marked no longer eligible.

Use warm, confident, nontechnical language. Prefer realistic portal walkthroughs, simple class-centered diagrams, button callouts, and coach-versus-teacher comparisons. Do not show API tokens, signing secrets, signed access parameters, passwords, credential contents, internal Tech Notes, technical board IDs, source code, or administrator screens.

## Recommended focus

- **Audience:** Kreyco coaches and teachers.
- **Knowledge level:** General portal users; no technical administration experience required.
- **Target length:** 5-7 minutes.
- **Primary goal:** Help coaches submit complete, class-specific requests and return to them later.
- **Secondary goal:** Help teachers understand their read-only progress access and why the request follows the class.
- **Tone:** Friendly, calm, reassuring, and action-oriented.

## Suggested video flow

### 1. Why the request exists

- Kreyco Tech uses the form to collect classroom setup information.
- One request covers one class.
- Tech can upload 3-5 lessons per class section per request.
- Allow 2-5 business days for completion.

### 2. The class-centered model

- Each class has its own request and portal link.
- The current teacher is displayed but does not own the request.
- A request stays with the class if the teacher changes.
- A class without an assigned teacher can still have a request.
- Another class creates another separate request.

### 3. Selecting the school and class

- The school list visibly loads active schools.
- Coaches can search and page through the list.
- Selecting a school loads its available classes.
- The class choice shows the current teacher or `No teacher assigned`.
- Classes with an existing request must be opened through their class-row link.

### 4. Completing the request

- Review or select the assigned coach.
- Use a manual coach contact only when necessary.
- Enter Language and Grade Level.
- Enter Kreyco Curriculum as text.
- Answer the LMS verification and Google Classroom grading questions.
- Enter another grading platform when Google Classroom is not used.
- Add credential access instructions and schedule details when needed.
- Use secure-share links instead of reusable passwords.

### 5. Draft versus submission

**Save as draft**

- Saves incomplete work.
- Does not notify Tech.
- Can be reopened from the class-row link.

**Submit to Tech**

- Requires all required fields.
- Notifies Tech.
- Opens the progress-summary experience.

**Submit & add another class**

- Submits the current class.
- Returns to class selection.
- Creates a separate request for the next class.

### 6. Returning to a request

- Use the Classroom Request Form link in the class row.
- A draft reopens for editing.
- A submitted request opens its progress summary.
- Use Refresh status for the newest Tech update.

### 7. Sending changes or additional information

**Edit request details**

- Corrects or changes the original fields.
- Updates the same request.
- Notifies Tech.

**Send additional information**

- Sends a note without changing the original fields.
- Adds the message to the same request.
- Notifies Tech.

### 8. Understanding progress

- Sent to Tech.
- Under Review.
- In Progress.
- Waiting for Information.
- Ready for Verification.
- Completed.

Explain that Tech may also show a public progress note and target completion date.

### 9. What teachers receive

- Tech may send an update to Coach or Coach + Teacher.
- Teachers receive a read-only progress link.
- Teachers can view status but do not edit coach-submitted fields.
- The request follows the class when teacher assignments change.

### 10. Getting help

- Wait for school and class loading indicators to finish.
- Confirm the correct school and class.
- Return through the current class-row link.
- Refresh the summary before reporting an outdated status.
- Contact Kreyco Tech Support for a missing class, invalid link, or ineligible request.

## Suggested coach-versus-teacher comparison

| Capability | Coach | Teacher |
|---|---|---|
| Start a class request | Yes | Not part of the standard teacher workflow |
| Save a draft | Yes | No |
| Submit to Tech | Yes | No |
| Edit submitted details | Yes, through the private coach link | No |
| Send additional information | Yes | No |
| View progress | Yes | Yes, through a read-only link when provided |
| Receive progress notification | Yes | Optional when Tech selects Coach + Teacher |
